## שלב 0 — ספיקים טכניים ✅

- [x] **S0.1 — סרגלי יישום (AppBar).** **אומת בהצלחה** ב-Windows 11 (build 26200):
      ארבעה סרגלים הצמיחו את אזור העבודה מ-`1920×1032` ל-`1820×992`, כלומר הוא נכנס
      לתוך האזור הגלוי. **מסקנה: מקסם, Snap וסרגל המשימות מכבדים את השוליים** —
      שכבה 1 עובדת, ואין צורך בנפילה החלופית בלבד.
- [x] **S0.2 — שכבת כיסוי וחסימת עכבר.** אומת: ארבע הרצועות נוצרות, מוצבות **בדיוק**
      לפי הגיאומטריה המחושבת (נבדק בקריאה חוזרת של המלבנים מהחלונות), וה-`ClipCursor`
      מוחל, נקרא בחזרה, ומשוחרר כראוי.
- [ ] **S0.3 — זיהוי מסך-מלא.** הקוד מיושם (`FullscreenWatcher`) אך **טרם נבדק מול דפדפן
      ב-F11 או נגן מדיה אמיתיים.** זה הפער המרכזי שנותר, ויש לסגור אותו לפני פרסום.
- [x] **S0.4 — תיעוד המסקנות.** בוצע: `DECISIONS.md` (D3) ו-`AGENT_LOG.md`.

### באגים שהתגלו בספיקים ותוקנו

- **גודל מבנה שגוי:** `Marshal.SizeOf<MONITORINFOEX>()` החזיר 72 במקום 104, בגלל חסר
  `CharSet.Unicode` על המבנה — ולכן `GetMonitorInfoW` נכשל בשגיאה 87 ומיפוי המסכים
  החזיר **אפס מסכים** בשקט, בלי חריגה. תוקן, ונוספה בדיקה קבועה לגודלי כל מבני האינטראפ.
- **נתיב ה-EDID ברישום:** `EnumDisplayDevices` מחזיר מזהה מופע סינתטי
  (`...\{guid}\0000`) שאינו קיים ברישום. הרשומה האמיתית נמצאת תחת מזהה חומרי שונה.
  תוקן באיתור לפי מזהה החומרה.

## שלב 1 — MVP ✅

- [x] שלד הפתרון: `FrameFit.slnx` + `FrameFit.Core` / `FrameFit.Platform.Windows` /
      `FrameFit.App` / `FrameFit.Core.Tests`
- [x] `DisplayService` — מיפוי מסכים, סוג חיבור (HDMI/DP/VGA/פנימי), EDID, גודל פיזי (FR-1)
- [x] מודל גיאומטריה + ולידציה + הגבלת ערכי סליידר, עם בדיקות יחידה (סעיף 4 בארכיטקטורה)
- [x] חלון ניהול בעברית RTL: ארבעה שוליים, סליידר + שדה מספרי לכל צד (FR-2)
- [x] מיני-מפה בחלון עם המלבן הגלוי המחושב
- [x] `OverlayHost` — שכבת כיסוי שחורה עם תצוגה מקדימה בזמן אמת על המסך (FR-3)
- [x] `InputGuard` — `ClipCursor` ומקש חירום גלובלי `Ctrl+Alt+Shift+F12` (FR-7, FR-9)
- [x] שחזור מלא: כפתור "שחזר הכול", ביטול אוטומטי של תצוגה מקדימה אחרי 20 שניות,
      שחזור ביציאה ובסיום התהליך
- [x] שמירה וטעינה של פרופיל JSON + זיהוי פרופיל לפי טביעת אצבע חומרית (FR-8, D7)
- [x] תמיכה במסך בודד ובמסך משני כאחד — כולל בחירה מפורשת של המסך

**לא בוצע בשלב זה:** טיפול בניתוק סשן ונעילת מסך (סשן RDP).
