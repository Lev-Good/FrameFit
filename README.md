# FrameFit

**FrameFit** — תוכנה ל-Windows שמתאימה את שולחן העבודה לשטח המסך שגלוי בפועל, כאשר מסגרת
(דקורטיבית, עץ, מתקן תצוגה) מכסה חלק מהשוליים — גם בצורה **לא-סימטרית**.

התוכנה מאפשרת להגדיר לכל צד בנפרד כמה פיקסלים מוסתרים, ולראות בזמן אמת כיצד השוליים
מסתדרים, כך שמסך-מלא, מקסם, סרגל המשימות וסמן העכבר יישארו בתוך האזור הגלוי בלבד.

## איך זה עובד

במסך מחשב **רגיל** אין דרך לגרום למנוע התצוגה של Windows לחתוך את שולחן העבודה באופן
לא-סימטרי. לכן FrameFit אוכף את האזור הגלוי בארבע שכבות בלתי-תלויות:

| שכבה | מה היא עושה | מה היא מכסה |
|---|---|---|
| **שטח עבודה (AppBar)** | מצמצם את `rcWork` של Windows בהתאם לשוליים | מקסם, Snap, סרגל המשימות |
| **שומר מסך-מלא** | מזהה חלון שמכסה את כל המסך ומתאים אותו לאזור הגלוי | דפדפן ב-F11, מצגות, שקופיות, נגני מדיה |
| **שכבת כיסוי** | ארבע רצועות שחורות תמיד-למעלה, עיוורות לקלט | שהשוליים ייראו שחורים וכבויים |
| **חסימת עכבר** | `ClipCursor` לאזור הגלוי | שהסמן לא ייכנס לאזור המוסתר |

## בנייה והרצה

```bash
dotnet build FrameFit.slnx

# הרצת אפליקציית הניהול
dotnet run --project src/FrameFit.App

# בדיקות יחידה
dotnet test tests/FrameFit.Core.Tests

# בדיקה עצמית מלאה של האינטראפ עם Windows
dotnet run --project src/FrameFit.App -- --self-test
```

אפשרויות נוספות:

| דגל | משמעות |
|---|---|
| `--self-test` | מריץ בדיקות אינטראפ ומחזיר קוד יציאה (0 = הכול תקין) |
| `--self-test --no-flash` | בלי להציג את שכבת הכיסוי למשך כשנייה |
| `--self-test --no-workarea-probe` | בלי לבדוק את צמצום אזור העבודה |
| `--self-test --out=<קובץ>` | שמירת פלט הבדיקה לקובץ |
| `--tray` | עלייה לסמל בסרגל המערכת בלי לפתוח חלון |

## בטיחות

התוכנה משתלטת על אזור העבודה, על סמן העכבר ועל שכבת התצוגה — ולכן כל שינוי הפיך:

* **מקש חירום גלובלי: `Ctrl + Alt + Shift + F12`** — מחזיר את Windows למצב נקי בכל רגע,
  גם כשהעכבר חסום לאזור הגלוי.
* "שחזר הכול" גם בסרגל המערכת וגם בחלון הניהול.
* תצוגה מקדימה מתבטלת אוטומטית אחרי 20 שניות אם לא אושרה.
* קובץ הגדרות פגום ⇒ לא מוחלת שום הגדרה, ומתחילים במצב כבוי.

## מגבלות מוצהרות

* מסך-מלא **בלעדי** של DirectX (משחקים) ומסך ההתחברות של Windows אינם מכוסים — מחוץ
  לתחום השימוש שהוגדר (ראו `docs/SPEC.md` סעיף 11).
* תוכנית שמחזירה את עצמה בכוח למסך-מלא תזוהה, והאכיפה תפסיק להילחם בה לאחר שלושה
  ניסיונות — ותדווח על כך באבחון.
* `ClipCursor` הוא ברמת הדסקטופ כל עוד התהליך פעיל; Windows משחרר אותו עם סיום התהליך.
